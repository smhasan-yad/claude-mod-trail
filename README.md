# claude-mod-trail

A live side pane of every file Claude reads or changes this session, in any folder (reads purple, writes orange, with +/- line counts). Watches tool calls only: zero tokens. `/trail` opens it.

## Install

```bash
claude plugin marketplace add smhasan-yad/claude-mod-trail
claude plugin install trail@claude-mod-trail
```

A new chat or /reload-plugins picks it up. Written for the Windows desktop app and terminal (Claude Code mods API); not tested elsewhere.
